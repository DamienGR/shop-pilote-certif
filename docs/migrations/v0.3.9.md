# Socle v0.3.9

<!-- Ce que cette version demande à une boutique qui la prend. Lu par
     `shopctl core upgrade` et repris dans la pull request de mise à niveau. -->

Cette version ferme ce que l'étape 6 de la certification (jalon 10,
`docs/certification/plan.md`) a trouvé en réel sur le staging de
`pilote-certif` en `v0.3.8` : la porte navigateur rouge sur la page de
contenu, et un rapport de mesure qui emportait le jeton de service d'Access.

## Ce qui change

Vitrine :

- **la prose des pages de contenu prend ses couleurs du thème.** Une citation
  était figée en gris `#6b7280`, le code et les blocs de code sur un fond
  clair `#f5f5f4`. Le bandeau « Brouillon » des pages légales (migration 0040)
  est une citation qui porte du gras et du code : publiée avant d'être
  supprimée, une page légale tombait sous le contraste AA sur les quatre
  thèmes livrés (4,37:1 sur atelier), et le code devenait illisible sous le
  texte clair de studio. La citation prend `--color-muted`, le code et les
  blocs de code `--color-surface`. Un thème de boutique qui définit ces deux
  jetons n'a rien à faire ; un thème qui ne les définit pas garde les anciennes
  couleurs.

Outillage :

- `npm run check:secrets` refuse un fichier qui porte la valeur de
  `cf-access-client-secret`, comme Lighthouse l'écrit dans chaque rapport
  quand on lui passe le jeton par `--extra-headers` ;
- la fiche de l'étape 6 masque les rapports Lighthouse avant qu'ils
  n'approchent le dépôt, ajoute le remote `core` qu'un clone neuf n'a pas, et
  dit ce que `wrangler tail` peut perdre.

## Migrations

- aucune.

## À faire dans la boutique

- rien dans le dépôt. Un thème propre à la boutique qui redéfinit la couleur
  des citations dans `.markdown-content` garde la sienne : la vérifier contre
  son papier.

## Compatibilité

Le manifeste ne change pas : un manifeste v0.3.8 reste valide tel quel, et
`shopctl core upgrade` met `coreVersion` à `0.3.9` tout seul.

Aucune migration : un rollback applicatif vers `v0.3.8` reste possible sans
intervention sur la base, et rend les anciennes couleurs.
