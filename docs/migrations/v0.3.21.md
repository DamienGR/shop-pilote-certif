# Socle v0.3.21

<!-- Ce que cette version demande à une boutique qui la prend. Lu par
     `shopctl core upgrade` et repris dans la pull request de mise à niveau. -->

Cette version raccourcit la CI d'une boutique : l'étape « Install Chromium »
des jobs Browser ne passe plus par apt (jalon 10). Rien ne change dans la
boutique elle-même.

## Ce qui change

- **Install Chromium sans `--with-deps`**, dans `verify.yml` et `nightly.yml`.
  L'étape prenait par moments dix minutes au lieu de vingt secondes, sur
  plusieurs jobs Browser d'un même run (trois sur cinq dans le run du
  2026-10-23 de pilote-certif). Le temps partait dans apt : `--with-deps`
  installait 25,9 Mo de paquets depuis `azure.archive.ubuntu.com`, qui les
  servait à 45 ko/s. Chromium lui-même vient du CDN de Playwright en cinq
  secondes. Ces paquets étaient des polices chinoises, japonaises, thaïes et
  bitmap X, plus des mises à jour de paquets déjà présents. Toutes les
  bibliothèques de Chromium sont déjà sur l'image du runner, qui embarque
  Google Chrome. L'étape lance maintenant Chromium une fois. Playwright vérifie
  les bibliothèques avant de démarrer un navigateur, et apt ne tourne que si
  l'une d'elles manque, avec un avertissement dans le run.

`test/scripts/workflows.test.mjs` refuse un `--with-deps` dans un workflow, et
veut la même étape dans les deux fichiers.

## Migrations

- aucune.

## À faire dans la boutique

- rien.

## Compatibilité

Le manifeste ne change pas : un manifeste v0.3.20 reste valide tel quel, et
`shopctl core upgrade` met `coreVersion` à `0.3.21` tout seul.

Aucune migration : un rollback applicatif vers `v0.3.20` reste possible sans
intervention sur la base.
